Features

What it does

Knowledge and study notes distilled from tech videos on Bilibili and YouTube: eight notes covering computer networking, operating systems, Git and GitHub, HTTP status codes, network protocols, CPU architectures, disk partitions, and database systems. Summaries are AI-assisted and manually reviewed for technical accuracy before publishing; every note ships in both Chinese and English.

🌐

Bilingual by design

Every note exists in Chinese and as an English translation in the en/ directory, with structure, math, diagrams, and commands preserved.

✅

Reviewed, not dumped

Before publishing, technical claims and worked examples are re-checked through independent review passes.

🔢

Worked examples re-verified

Calculations, formulas, and command behavior are recomputed and confirmed line by line.

📚

Eight core CS topics

From the five-layer networking model and OS scheduling to database normalization and CPU architecture comparison.

🗂️

Exam-oriented format

Revision-outline style notes for fast recall of a course's core conclusions and classic problems.

⚖️

Sources & attribution

Known sources are credited at the end of each note; content owners can request removal or correction via issues.
